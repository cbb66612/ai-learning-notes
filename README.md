# 麦香冰的 AI 学习笔记 ✦

这里记录我对产品、Agent、评测与 FDE 的学习。我把 Obsidian 中分散的笔记按问题重新整理，留下概念解释、具体例子、容易混淆的地方，以及可以继续动手的小练习。

## 怎么阅读

可以从当前遇到的问题开始，不必按目录顺序读完。第一次读先抓住核心概念，再试着用自己的例子解释；做过练习后，把新的理解补回笔记。技术细节会变化，我也会随着阅读和尝试继续修订。

我会在 Obsidian 的“05-公开学习笔记”目录中继续修改这些 Markdown，GitHub 每月同步一次。
