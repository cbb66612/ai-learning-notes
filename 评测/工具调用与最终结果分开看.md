# 工具调用与最终结果分开看

Agent 任务里，许多“看起来成功”的信号只覆盖某一个阶段。我把它们排成一条链：

```text
选择工具 → 实际调用 → 请求被接收 → 任务状态成功
        → 文件或链接可用 → 成品内容符合目标
```

前一步成立，不自动推出后一步成立。比如界面显示任务成功，仍需打开产物，看内容、时长或格式是否符合要求。

## 记录一次任务

| 字段 | 要写清什么 |
| --- | --- |
| 目标与输入 | 原始请求、约束和预期结果 |
| 工具轨迹 | 工具名、参数、返回和错误 |
| 任务状态 | 已提交、运行中、成功或失败 |
| 实际产物 | 文件、链接以及能否打开 |
| 内容检查 | 与目标不一致的具体地方 |
| 未检查项 | 不能靠状态推断的部分 |

图像需要看实际画面；视频要看可解码、时长和关键帧，声音还需单独听检。没有检查过的维度就写“未检查”。这让问题定位和下一次回归都更明确。
